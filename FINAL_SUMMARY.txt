USER CREATES CAMPAIGN
         ↓
SENDS TO BACKEND API
         ↓
BACKEND CALLS AI ENGINE
         ↓
AI ENGINE SCORES INFLUENCERS
         ↓
BACKEND ENRICHES WITH DB DATA
         ↓
STORES IN RECOMMENDATION HISTORY
         ↓
RETURNS TO FRONTEND
         ↓
FRONTEND DISPLAYS CARDS
         ↓
USER VIEWS RESULTS & HISTORY

IF AI ENGINE UNAVAILABLE:
→ Fallback scoring used automatically
→ System still works perfectly
